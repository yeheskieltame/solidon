## How Solidon maps to the tracks

| Criterion | Evidence in Solidon |
| --- | --- |
| `defi`: cross-chain settlement | Enter from any chain via NEAR Intents 1Click (live dry quotes in the app); treasury cash sent to Base, Robinhood Chain and Solana, through Intents on mainnet |
| `defi`: no custodian | Treasuries at contract-owned addresses via Chain Signatures; `rebalance()` callable by anyone |
| `defi`: exchange and vault | Internal AMM pool and a per-meme stock vault on three chains |
| `memecoins`: mechanic in the contract | mNAV engine, issuance, buyback and redemption all run in the meme contract |
| `memecoins`: locked parameters | Parameters locked at launch, publicly readable, no admin key |
| `memecoins`: treasury with rules | 20% cash buffer, 1% per day issuance cap, redemption window |
| `memecoins`: simulation | 60-day simulation across five scenarios. See [Simulation](/docs/simulation) |
| `memecoins`: sybil resistance | No per-account rewards; every mechanic is proportional to token amount |
| `open`: something new | A memecoin that is also a treasury company: one NEAR contract holds a tokenized stock on three other chains through Chain Signatures, under capital rules no one can change |
| `open`: chain abstraction | Users stay on NEAR; the contract signs EVM (ECDSA) and Solana (EdDSA) transactions itself, and anyone can broadcast them |
