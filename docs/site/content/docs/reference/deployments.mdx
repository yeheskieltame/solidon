Everything runs on testnets. Stock tokens are synthetic (Solidon-deployed), priced from the official Chainlink feeds on Robinhood Chain mainnet; the test USDC has no value. Source files: `docs/DEPLOYMENTS.md` and the venue registries in `contracts/stocks/`.

| Landing | https://solidon.xyz |
| Read API | https://api.solidon.xyz (see [API](/docs/reference/api)) |

## Older contracts

Memes launched by earlier factory code (BSC era, before 10 Nov 2026) still exist, because memes have no access key, but they are not listed by the current factory: `nvda.solidon.testnet`, `elondoge.solidon.testnet`, and the Chain Signatures test account `chainsig-e2e.solidon.testnet`. The keeper gives memes without `get_treasury_chains` only `rebalance()`.

<Callout type="warn" title="Factory key">
During development the factory account still has a full-access key, which could redeploy the factory. Launched memes have no access key. See [Security](/docs/security).
</Callout>
